# Kunden-Logos

Drop the client logo files in here, then run `npm run migrate:images`.

One file per client, named after the client, lower case:

    canon.svg      arri.svg     tufa.svg     opel.svg
    adc.svg        lillet.svg   arteholic.svg

`.svg` is preferred; `.png` works too — use a high-resolution one, at least
600 px wide. The page renders every logo in the same light grey and shows the
client's name as text wherever a file is missing, so a half-filled folder is
fine.
